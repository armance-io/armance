Usage

Notes

  • Conserve la classe .chapter-fleuron — les ancres CSS existantes de styles4.css continuent de s'appliquer.
  • Aucune clé i18n — aucun texte visible.
  • Pas d'animation — prefers-reduced-motion satisfait sans condition.
  • Strict TypeScript, aucun any, ~85 LOC.

  • La taille du glyphe est 0.6 × diamètre (33 / 52 / 76 px selon sm / md / lg).
  • Aucune clé i18n — aucun texte visible en dur.

ThemeToggle

visual/ThemeToggle.tsx

Bouton circulaire 32 × 32 qui bascule data-theme sur <html> et persiste le choix dans localStorage. Au montage, lit la valeur stockée ou interroge prefers-color-scheme. Icône soleil / lune avec swap animé 200 ms.

Les deux états

light · soleil
dark · lune

Demo interactive · bascule le thème de cette page

Cliquez pour basculer le thème

Props

PropTypeDéfautDescription
t (key: string) => string — Fonction i18n. Clé utilisée : visual:theme.toggle_aria.
className string — Classes supplémentaires sur le <button>.

Clés i18n

CléUsageExemple FR
visual:theme.toggle_aria aria-label du bouton « Basculer le thème »

Usage

// import
import { ThemeToggle } from "@/components/visual/ThemeToggle";

// dans le header
<ThemeToggle t={t} />

// avec classe Tailwind
<ThemeToggle t={t} className="ml-auto" />

Notes

  • Lit localStorage.getItem("armance.theme") au montage ; fallback sur window.matchMedia("(prefers-color-scheme: dark)").
  • Écrit document.documentElement.dataset.theme à chaque bascule — toutes les variables CSS réagissent instantanément.
  • Swap animé 200 ms (fade + scale + rotate) ; supprimé si prefers-reduced-motion: reduce.
  • aria-pressed reflète l'état courant (true = dark).

import { EmptyWorkflow } from "@/components/visual/EmptyState/EmptyWorkflow";

Notes

  • Les trois variantes partagent la coque interne EmptyShell (non exportée). Chaque variante n'expose que ses clés i18n.

  • Le titre utilise text-wrap: balance pour des coupures de lignes équilibrées.
  • Annonce ARIA : role="status" + aria-live="polite" — les lecteurs d'écran annoncent le titre quand le volet bascule en état vide.
  • Le fleuron utilise le composant <Fleuron size="sm" /> — garantit la cohérence visuelle avec les autres séparateurs.

LibraryPane

library/LibraryPane.tsx

Liste les documents de .armance/docs avec nom, format, statut et taille. Barre d’outils : recherche · filtre format · « Tout indexer » (si docs en attente) · « Importer ». Actions par rang : indexer / charger / décharger / désindexer / supprimer avec confirmation inline.

Demo interactive · toutes les actions fonctionnent

Props

PropTypeDescription

onIndex / onLoad / onUnload / onUnindex(name) => Promise<void>Actions unitaires.
onDelete(name) => Promise<void>Suppression réelle, appelée après confirmation.
t(key) => stringi18n — clés library:*.

Usage

import { LibraryPane } from "@/components/library/LibraryPane";

<LibraryPane
  docs={library.docs}
  onImport={handleImport}
  onIndexAll={handleIndexAll}
  onIndex={handleIndex}
  onLoad={handleLoad}
  onUnload={handleUnload}
  onUnindex={handleUnindex}
  onDelete={handleDelete}
  t={t}
/>

Notes

  • Confirmation inline — onDelete n’est appelé qu’après accord de l’utilisateur.
  • « Tout indexer » n’apparaît que si au moins un doc est pending.
  • busy tracé par nom de doc : plusieurs opérations peuvent s’exécuter simultanément.
  • Affiche <EmptyLibrary> (CTA Importer) quand docs est vide.
  • Accepts .pdf .docx .md .txt uniquement.
