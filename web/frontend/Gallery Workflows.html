DepthPicker

Interface de lancement de tâche permettant de sélectionner la profondeur d'exploration ("Lancement rapide" contre "Analyse approfondie") et le mode de validation (Interactif ou Autonome).

Démo interactive

Lancer une nouvelle session d'archivage

Lancement Rapide
Analyse les sources superficielles et renvoie des fiches d'hypothèses en quelques minutes.
Analyse Approfondie
Exécute des boucles cognitives profondes avec réfutation des arguments contradictoires.

Mode Interactif : Les agents rédigent les livrables mais s'arrêtent pour valider chaque pivot critique avec vous.
