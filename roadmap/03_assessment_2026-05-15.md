Armance's hand-off-ready story has tightened. Eleven targeted commits closed five of the six remediation phases from the 2026-05-14 plan plus the three review recommendations that came out of the senior-dev hand-off audit:

## 3. Known open items (priority-ordered)

### 3.1 Workflow engine duplication (highest impact)

Unchanged from 2026-05-14 §2. Two `Workflow` classes, two engines, the rich features (Serge auto-invoke, cross-family validation, consensus, run events) only fire on `operator_agent` paths. `handlers._cmd_workflow_run` still loads via the simple core engine.

Cost to fix: ~1.5 days (was budgeted as P1.1).

### 3.2 `handlers.py` second-half split

Remaining 1245 LOC is dominated by:
- `_cmd_chat` router (~80 LOC)
- `_cmd_context_chat` (Armance chat shell, ~80 LOC)
- `_cmd_hr_chat` (Malik chat shell, ~250 LOC) — couples to provider catalogue injection
- `_cmd_orchestrator_chat` (Kim chat shell, ~180 LOC) — couples to workflow design
- `_cmd_workflow_run` + preflight (~130 LOC)
- `_cmd_task` / `_cmd_judge` / `_cmd_report` / `_cmd_export` / `_cmd_deliverable` (~300 LOC)

The three chat shells are coupled to the (provider catalogue, RAG injection, workflow design) cross-cutting concerns. Splitting them is more invasive than the library / save / role extractions and should happen alongside the workflow engine unification (so the workflow chat handler can be slimmed in the same pass).

Cost to fix: ~1 day if done together with P1.1; ~0.5 day stand-alone.

### 3.3 DesignWorkflowSkill still template-literal

Unchanged from 2026-05-14 §2.2. Kim's S2 step picks one of three hard-coded step lists regardless of project. The QA `M` section (workflow tailoring) does catch this today, but the fix has not landed.

Cost to fix: ~0.5 day (a single LLM call at S2, with `Workflow.model_validate` fallback to template).

### 3.4 `rag_service.py` re-export shim

One file, one consumer, never inlined. Quick win.

Cost to fix: ~15 min.

### 3.5 qa_live gaps: J / K / N

- **J** — checkpoint round-trip with `AutoApproveCheckpointHandler`
- **K** — deliverable rendering (PDF / DOCX / PPTX bytes on disk ≥ 1 KB)
- **N** — rich-engine consensus / Serge auto-invoke signal assertion

K and N depend on P1.1 (rich engine wired into the user path).

### 3.6 Kim / Mona / Serge prompt diet

Phase E from the 2026-05-14 plan applied only to Armance and Malik this cycle. Kim (~70 lines), Mona (~45 lines), Serge (~40 lines) are still verbose. Free-model context budget pressure stays elevated until this lands.

Cost to fix: ~0.5 day across the three files.

### 3.7 `questionary` calls inside service/handlers

`_cmd_workflow_run` preflight still calls `questionary.text()` / `questionary.confirm()`. Web has no TTY. Route through `ctx.checkpoint_handler` before P2.

Cost to fix: ~0.5 day (couples to P1.1 cleanup).
