# Catégorisation des métiers (grille ESN)

Grille de référence pour composer une équipe et positionner les profils
dans un chiffrage. Les niveaux conditionnent le TJM ; la grille interne
du département fait foi quand elle existe (la charger dans la library) —
sinon utiliser ces catégories comme vocabulaire commun.

## Familles de métiers

| Famille | Profils types | Intervient sur |
|---|---|---|
| Pilotage | Directeur de projet, chef de projet, PMO, Scrum Master | Gouvernance, planning, comitologie, risques |
| Conseil | Consultant métier, product owner délégué, UX researcher | Cadrage, ateliers, expression de besoin |
| Architecture | Architecte d'entreprise, architecte solution, architecte cloud, architecte data | Dossiers d'architecture, choix structurants |
| Développement | Développeur back / front / fullstack, tech lead | Réalisation, revues, qualité de code |
| DevOps / plateforme | Ingénieur DevOps, SRE, ingénieur plateforme | CI/CD, IaC, observabilité, MCO |
| Data / IA | Data engineer, data scientist, ingénieur ML/LLM, expert IA générative | Pipelines, modèles, RAG, gouvernance IA |
| Sécurité | Architecte sécurité, pentesteur, analyste SOC, RSSI délégué | Volet sécurité, homologations, audits |
| Design | UX designer, UI designer | Parcours, maquettes, design system |

## Niveaux de séniorité

| Niveau | Expérience indicative | Usage en chiffrage |
|---|---|---|
| Junior | < 3 ans | Tâches encadrées ; jamais seul sur un lot |
| Confirmé | 3-7 ans | Autonome sur son périmètre |
| Senior | 7-12 ans | Référent technique, encadre, arbitre |
| Expert / principal | > 12 ans ou expertise rare | Interventions ciblées, ratio faible mais TJM haut |

## Règles d'usage

- Un chiffrage nomme des **profils** (famille × niveau), jamais des
  personnes. La composition nominale vient au moment du plan de charge.
- Ratio d'encadrement usuel : 1 senior pour 3-4 confirmés/juniors sur un
  même lot ; en dessous, le risque qualité se provisionne.
- Les expertises rares (sécurité offensive, IA générative avancée,
  SecNumCloud) se chiffrent en jours ciblés, pas en présence continue.
- Public / défense : certains postes exigent habilitation (voir
  typologie-clients) — le préciser profil par profil dès la réponse.
